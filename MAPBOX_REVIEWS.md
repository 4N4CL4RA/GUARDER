# 🗺️ Guarder - Sistema de Avaliações de Segurança com Mapbox

Sistema completo de avaliações de segurança georreferenciadas usando Mapbox GL JS e Supabase.

## 🚀 Funcionalidades Implementadas

### 📍 Mapa Interativo
- **Mapbox GL JS v3.14.0** com projeção globe
- **Clique para avaliar**: Clique em qualquer local do mapa para adicionar uma avaliação
- **Marcadores coloridos**: Baseados no nível de segurança (1-5 estrelas)
- **Popups informativos**: Mostram detalhes das avaliações ao passar o mouse
- **Navegação**: Zoom, pan e controles de navegação

### ⭐ Sistema de Avaliações
- **Ratings de 1-5**: Sistema de classificação de segurança
- **Comentários opcionais**: Descrição detalhada da experiência
- **Dados georreferenciados**: Coordenadas precisas (lat/lng)
- **Timestamps**: Data e hora das avaliações
- **Interface intuitiva**: Formulários responsivos e amigáveis

### 🗃️ Base de Dados
- **Supabase PostgreSQL**: Backend robusto e escalável
- **Row Level Security (RLS)**: Políticas de segurança configuradas
- **Spatial Data**: Suporte a coordenadas geográficas
- **Índices otimizados**: Performance para queries geoespaciais
- **Backup automático**: Dados seguros e recuperáveis

## 🛠️ Arquitetura Técnica

### Frontend (React + TypeScript)
```
src/
├── components/
│   ├── InteractiveMap.tsx       # Componente principal do mapa
│   ├── ReviewForm.tsx           # Formulário de avaliação
│   └── ReviewList.tsx           # Lista de avaliações
├── services/
│   └── reviewService.ts         # API de comunicação com Supabase
├── types/
│   └── review.ts               # Definições de tipos TypeScript
├── utils/
│   └── setupDatabase.ts        # Scripts de configuração DB
└── pages/
    └── mapa.tsx               # Página principal do mapa
```

### Backend (Supabase)
```sql
-- Tabela de reviews
CREATE TABLE reviews (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID,                    -- Usuário (opcional)
  rating SMALLINT NOT NULL,        -- 1-5 estrelas
  comment TEXT,                    -- Comentário (opcional)
  lat NUMERIC(9,6) NOT NULL,      -- Latitude
  lng NUMERIC(9,6) NOT NULL,      -- Longitude
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Políticas RLS
- Leitura pública (todos podem ver)
- Inserção para usuários autenticados
- Edição/exclusão apenas pelo autor
```

### Mapbox Integration
- **Token**: Configurado via variáveis de ambiente
- **Estilo**: `mapbox://styles/mapbox/light-v11`
- **Projeção**: Globe para visualização global
- **Marcadores**: Customizados com cores baseadas no rating
- **Popups**: HTML customizado com informações das avaliações

## 🚀 Como Usar

### 1. Configuração Inicial
```bash
# Instalar dependências
npm install

# Configurar variáveis de ambiente (.env)
VITE_SUPABASE_ANON_KEY=sua_chave_supabase
VITE_MAPBOX_TOKEN=seu_token_mapbox

# Executar script de inicialização do banco
npm run setup-reviews
```

### 2. Executar em Desenvolvimento
```bash
npm run dev
# Acessar: http://localhost:8081/mapa
```

### 3. Usar o Sistema
1. **Navegar**: Use mouse/touch para navegar pelo mapa
2. **Avaliar**: Clique em qualquer local para adicionar avaliação
3. **Consultar**: Clique nos marcadores para ver avaliações existentes
4. **Explorar**: Use o painel lateral para filtrar e explorar
